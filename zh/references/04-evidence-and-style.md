# 04　证据、数值与写作规范

> 本文件定义"笔记里的每句话凭什么成立"。写作或自检时读；与 `scripts/check_note.py` 的检查项一一对应。

## 一、定位符（证明"这句话从哪来"）

| 类型 | 写法 | 使用场景 |
|------|------|----------|
| 小节 | `[§4.2]` | 论文有编号章节 |
| 印刷页 | `[p.7]` | 书/期刊页码 |
| 物理页 | `[PDF p.12]` | PDF 阅读器页码（与印刷页不同时并列） |
| 表 | `[Table 2]` | 结果表、消融表 |
| 图 | `[Fig. 3]` | 架构图、曲线、可视化 |
| 公式 | `[Eq. (1)]` | 关键公式 |
| 行号 | `[L120–135]` | LaTeX 源码或纯文本 |
| 版本 | `[arXiv v7, §3.1]` | 预印本必带版本 |
| 笔记 | `[note:paper_id §5]` | 综述里引用自己的笔记 |

**规则**
- 定位到最小可核对单位：能到 §4.2 就不写 §4。
- 一句话多个来源时分别标：`[p1 §3][p2 Table 1]`。
- 图表引用写清是哪一部分：`[Table 2 左下]`、`[Fig. 4 右]`。
- 不能定位的内容不写进正文；确需提及则放"信息缺口"。
- **公式编号闭环**：引用 `[Eq. (x)]` 时，若该式尚未在笔记中出现，就在引用处写出公式；范围引用（如 `Eq. (A4)–(A12)`）只保留已在笔记中展示的编号。

## 二、四类标签（区分知识来源）

| 标签 | 含义 | 示例 |
|------|------|------|
| `[原文]` | 论文明确写了（转述或引用） | `28.4 BLEU [原文][Table 2]` |
| `[推断]` | 我基于证据的推理，论文未直接说 | `说明作者更看重并行度 [推断][§1]` |
| `[外部: 来源]` | 论文之外的知识，必须给来源 | `后续 BERT/GPT 沿用该架构 [外部: Devlin et al. 2019]` |
| `[疑问]` | 没读懂/待核实 | `基线是否同预算调参？[疑问]` |

- 标签与定位符连用，顺序：`内容 [标签][定位]`。
- 不确定是原文还是推断时，按 `[推断]` 处理。
- 外部知识若无法给来源，删除或改为 `[疑问]`。

## 三、原文引用规则

1. **逐字**：引号内不改写、不省略词；省略用 `……`，并保证不改变原意。
2. **短**：单条 ≤2 句；长段落只摘关键句。
3. **带定位**：每条引用给页码/小节。
4. **译文标注**：中文译文放引文后，标"（译）"；术语保留英文原文。
5. **不把转述当引用**：转述用 `[原文]` 但不加引号。

## 四、数值纪律

| 规则 | 错误示例 | 正确示例 |
|------|----------|----------|
| 原样抄录 | "提升约 47%"（用 28.4 与 41.8 两个不同任务的数硬算） | `EN-DE 28.4 BLEU [Table 2]` |
| 相对/绝对分开 | "提升了 2 倍"（未说明口径） | `相对提升 12.5%（绝对 +4.6）` |
| 不跨设置比较 | "A 的 90.1 > B 的 88.0"（不同数据集/指标） | `同数据集、同指标下：A 90.1 vs B 88.0` |
| 保留精度 | "约 28"（原文 28.4） | `28.4` |
| 未报告不推算 | "大约 3 天"（原文未给） | `未报告训练时长` |
| "显著"需检验 | "显著优于"（无检验） | `提升 2.0 BLEU（未报告显著性检验）` |
| 单位/指标写全 | "准确率 95" | `top-1 accuracy 95.0%（ImageNet）` |
| 区分均值与最好值 | "达到 90"（其实是 best-of-5） | `best-of-5 90.2；均值 88.7±0.6` |

**数值三问**：这个数字对应哪个数据集/指标/设置？是均值还是最好值？有没有方差/检验？

## 五、措辞阶梯（按证据强度选词）

| 证据强度 | 可用措辞 | 不能用的措辞 |
|----------|----------|--------------|
| 多数据集+多种子+检验 | 证明、确立 | — |
| 多数据集、无检验 | 表明、显示 | 证明 |
| 单数据集、有对照 | 报告、在 X 上优于 | 普遍优于 |
| 单次运行/无对照 | 报告了一个结果 | 显著提升 |
| 仅作者声称、无证据 | 作者声称 | 事实是 |
| 我的推理 | 我认为、可能、推测 | 显然 |

**降级写法示例**
- 原文：`Our method significantly outperforms all baselines.`
- 差：`该方法显著优于所有基线。`（照抄强度）
- 好：`作者报告在 WMT14 EN-DE 上比此前最佳（含集成）高 2.0+ BLEU [原文][Table 2]；未报告显著性检验 [疑问]。`

## 六、禁用表达与替换

| 禁用（无证据的套话） | 替换 |
|----------------------|------|
| 效果很好 / 性能优异 | 给出指标、数据集、对比对象 |
| 很有创新性 / 颠覆性 | 说明相对哪篇工作、改变了什么假设 |
| 具有重要意义 | 说明影响谁、影响哪个决策 |
| 大量实验 | 说明几个数据集、几组消融 |
| 作者做了深入分析 | 说明具体分析了什么、得出什么 |
| 众所周知 / 显然 | 给引用或删掉 |
| 本文旨在 / 笔者以为（论文腔） | 直接陈述 |

## 七、中文笔记文风

- **结论先行**：每段第一句是判断；后面是证据与限定。
- **一段一论点**：长段落拆分；列表用于并列事实，不用于论证。
- **术语一致**：同一概念全文用同一译名；首次出现 `中文（English）`，之后只用其一。
- **少用连接词堆砌**：避免连续"此外/而且/同时"；用逻辑关系词（因为/但是/因此）。
- **数字与单位**：中英文之间加空格；百分号紧贴数字；范围用 `–`。
- **公式**：LaTeX；符号优先集中到文首符号表（含义 + 量纲 + 归一化/取值），表已覆盖的符号正文首次出现可只给一句角色说明，表未列的符号（含 $\phi_j$、$\psi_j$ 等下标变量）在首次出现处定义；关键公式要写"含义、符号、推导动机、思想来源、作用、假设"，不能只抄公式；引用原文编号时，若该式尚未在笔记中出现，须在引用处写出公式；每个公式表格下方（表格外）写"推导过程"（从动机/来源分步到目标式），推导写清后表格的动机/来源可精简。
- **公式链**：4.3 先写 4.3.0 推导主线（从哪出发、每步为什么引入、下一式接什么），再逐式展开；不要只给公式清单。
- **公式渲染**：数学模式内不放中文（`\text{}` 内不出现 CJK，中文写公式外）；行间公式用多行 `$$`（`$$` 单独占行）；表格内用 `\lvert...\rvert` 代替裸 `|`；渲染失败时查看器会回退显示原始源码，需检查。
- **推导语体**：4.3 推导用论文式陈述（设/令/由…得/于是/故/唯有），不写教学式分步编号，也不写"这一步的必要性""不构成循环论证"一类元话语；关键式独立成段并标原编号。
- **推导不跳步**：4.3 推导要给出每一步所依据的原始公式，并说明做了什么操作（代入/展开/平均/分部积分/取极限）；移项、合并同类项、两边同乘等基础代数不必展开；禁止"由 Eq. X 得 Eq. Y"而不交代依据。引用附录式先展示该式。其他章节可概括，推导块不可。代入、求导、赋值、两式相减要写出中间结果（可放行内），不能从一步直接跳到结论。
- **起始式标注来源**：给出初始表达式时说明它是定义、公认事实/守恒律、前文结论（Eq. x），还是论文假设；同一式标一次即可，后文引用不必重复。复合式先写最简情形，再说明新增项为何加入。"取 X=…"必须说明依据（前文 Eq. x 或某条假设）。
- **新假设先声明**：引入新假设或拟设（完全同步→部分同步、单群→多群等）时，先用一句话写清假设内容、与上一情形的区别、哪一式随之改变，再给公式。
- **首次出现的公式要说明来路**：正文第一次给出某公式时，写清它由哪几式联立/代入或哪条近似得到；不能只标编号或只写"由 A6"；推导在附录时，正文给一句来源并指向附录。
- **关键判断给机制**：遇到"唯有…才…""必然…""等价于…""只有…稳定"这类判断，写"判断 → 1–3 式最小机制（线性化/符号分析/守恒/极限）→ 一句直觉 → 边界"；不写完整证明，也不只下结论。线性化写出 Taylor 展开（一阶项 + 余项），不能只写"线性化得"。
- **读者标记与附录 1**：读者用 `<u>术语</u>$^{[n]}$` 标出不懂的名词或推导步骤时，保留标记与编号；下划线只划文字，公式放在 `<u>` 外（数学渲染不继承下划线）。在文末 `## 附录 1：术语与步骤解释` 按编号逐条解释——术语给"定义 + 作用 + 区别"，步骤先写"目标：要推导的是 (x) 式"再给"做了什么 + 为什么成立 + 近似/边界在哪"，每条 2–4 句；附录不计入正文长度。
- **附录引用公式要展开**：附录里第一次提到正文编号公式时，用行间公式写出该式并保留编号，不只写编号。
- **编号公式不能裸引用**：当前页面看不到的编号公式，引用处必须写出该式并保留编号；重要公式（机制链、结论、关键推导）用行间公式，次要公式用行内公式；表格速查尽量带简式。
- **符号语义三查**：用符号前查原文定义处与原句、查类型（计数/密度/振幅/频率/相位）与量纲、用归一化或量纲做一致性验算；文字说法与积分/量纲对不上时，停笔核对原文，不猜。
- **附录推导用行间公式**：附录推导以 `$$` 行间公式为主，行内只留符号与短表达式；目标式、关键中间式、结论独立成段，一条推导链通常 2–4 个行间公式。
- **编号公式用行间**：带编号公式（`Eq. (x)`、`(a)(b)(c)`、`(A1)` 等）首次出现时用 `$$` 展示并标编号；后文引用可只写编号或行内简写，不要把编号公式埋在行内。
- **图先讲轴再讲含义**：每幅图先写横轴、纵轴各是什么（变量 + 单位/范围），图例/区域各代表什么，再用一句话说这张图想表达什么；图注 1 句、图说明 3–8 句，不许只放图不解释；图注与图说明不计入正文长度。
- **语病检查**：写完推导逐句通读，检查主语残缺、搭配不当、成分赘余、逻辑重复（如同一个假设拆成"既…又…"）、指代不明；发现问题就地改写。
- **句式禁忌**：不使用"不是…而是…""并非…而是…"这类否定式对举；改为正面陈述（先说是什么，必要时再补边界）或拆成两句。图注、附录、表格说明同样适用。
- **领域导读**：L2/L3 在 §0 前写 2–3 段"领域在做什么"：研究对象与典型现象、三层问题（单振子 PRC / 成对锁定 / 群体阈值与频率）、本文补哪一层。只给背景，不写本文结论；可配自绘示意图，图注标"自绘，非原文"。
- **图表嵌入**：原文图从 PDF 裁切（建议连图注，保证坐标轴与标注完整），存 `notes/figures/`，用相对路径；一图一行、居中（`<p align="center"><img …></p>`），不要多图挤在一行；图注写图号 + 页码 + 一句话；自绘图与原文图分开标注。
- **不写"论文说"**：直接写内容，定位符负责归属。

| 坏 | 好 |
|----|----|
| 作者提出了一个新框架，取得了很好的效果。 | 用纯注意力堆叠替代循环结构，在 WMT14 EN-DE 上达到 28.4 BLEU，比此前最佳（含集成）高 2.0+ [原文][Table 2]。 |

## 九、引用格式

正文引用：`作者（年份）` 或 `[作者, 年份]`；同一处多篇：`[Vaswani et al., 2017; Devlin et al., 2019]`。

文末条目（择一，全文统一）：

```text
Vaswani, A., Shazeer, N., Parmar, N., et al. (2017). Attention Is All You Need.
  Advances in Neural Information Processing Systems, 30. arXiv:1706.03762v7.
  https://arxiv.org/abs/1706.03762
```

规则：
- 预印本标版本与访问日期；正式发表后优先引正式版。
- 有 DOI 给 DOI；网页给 URL + 访问日期。
- 不引用没读过的文献；二手引用标"转引自"。

## 十一、本 Skill 的高频反模式

| 坏写法 | 好写法 |
|---|---|
| "由 Eq. (2) 得 $d\psi/dt=\dots$" | 先写 $d\phi/dt=1/T+\Delta f$、$d\theta/dt=f_s$，再相减并代入 Eq. (2) |
| "线性化得 $d\delta\psi/dt=M'\delta\psi$" | 写出 Taylor：$M(\psi^*+\delta\psi)=M(\psi^*)+M'\delta\psi+\mathcal O(\delta\psi^2)$，常数项相消后再略去二阶 |
| "图 2：V 形夹带区。" | 横轴 $f$、纵轴 $|S|$；V 对应 $mf_s=n/T$，V 内锁定、V 外不能；宽度 $\propto|S|$ |
| "以 $p(\psi)$ 将求和化为积分。" | 按 $\psi$ 分组，$p(\psi)d\psi$ 为相位差在 $[\psi,\psi+d\psi)$ 的振子数，$\int p\,d\psi=J$，求和近似为积分 |
| "$X$ 是影响函数。" | $X(\phi_j)$ 是相位 $\phi_j$ 处振子对他人的影响强度（p.23）；$\phi_j$ 为第 $j$ 个振子相位，$\psi_j=\phi-\phi_j$ |
| "唯有下降沿稳定。" | 线性化 + 符号判断 + 一句直觉 + $\mathcal O(S^2)$ 只改数值的边界 |
