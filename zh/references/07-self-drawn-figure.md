# 07　自绘示意图的版式规则与自检

> 适用：笔记 §0 前的领域导读图、方法总览图、概念图等**自己要画的图**（图注须标"自绘，非原文"）。
> 目标：自绘图不出四类硬伤——**箭头穿框、箭头悬空、标签指向空白、留白/对齐失衡**。
> 工具：`scripts/draw_schematic.py`（画的时候自动吸附端点、保存前跑几何断言）＋ `--check`（检查已有 PNG）。

## 一、为什么单独立规则

原文图从 PDF 裁切，版式由期刊负责；自绘图由 Agent 现写代码，最容易出的不是"画得难看"，而是
几何关系错误：箭头端点落在方框内部、压住框内副标题、回路少接一段、标注箭头指向两块内容之间的空白。
这类错误在缩略图里看不出来，放大后才明显，而读者会据此误解图的语义（以为循环断了、以为某两步之间没有关系）。

`check_note.py` 只检查"有没有图、图注有没有图号页码、有没有横纵轴说明"，查不出上面这些问题；所以自绘图必须再过一遍几何自检。

## 二、版式硬规则（画之前先定死）

| # | 规则 | 具体做法 | 违反后果 |
|---|------|----------|----------|
| 1 | **端点吸附** | 箭头端点一律取方框边中点，再沿外法线外移 `pad`（默认 0.9 个单位）；**不要**手写端点坐标 | 箭头扎进框里、压住副标题 |
| 2 | **两端有主** | 每个箭头都必须声明 `src/dst` 与各自的边；做不到就说明这个箭头该删或改成文字标注 | 悬空箭头：回路看着断了一截 |
| 3 | **共线** | 水平/竖直箭头两端必须在同一 y / 同一 x（差 ≤ 0.8 单位）；斜箭头只用于真正对角的关系 | 箭头歪斜、与方框不成网格 |
| 4 | **不穿框** | 箭道路径（含弯曲段）与任何方框内部不相交；需要绕行时改布局，不要靠曲率硬绕 | 箭头横穿别的步骤框 |
| 5 | **等大等距** | 同一组方框宽高一致（差 ≤ 0.05），同向间距一致（差 ≤ 0.5）；三联/四联结构对称 | 一眼看出"手抖"，读起来像漏了一步 |
| 6 | **文字在框内留边** | 标题、副标题距框边 ≥ 0.3 单位；副标题过长就缩字号或拆两行，**不许压线** | 文字贴边/出框 |
| 7 | **标签不压线** | 箭头标签、图注与方框、箭头、其他文字都不重叠；标签放在箭头中点旁 `label_off` 处 | 标签糊在箭头上 |
| 8 | **留白相等** | 先排内容，再由内容包围盒反推画幅：四边留白取同一绝对值（默认 2.5 单位），**不要**手写 `figsize` 和 `xlim` | 某一边留一大片白、整体重心偏移 |
| 9 | **字号分级** | 面板标题 11 / 框标题 9.5 / 副标题与标签 7.6–8；相邻层级差 ≥ 1.5 pt，同级同字号 | 层级混乱、主次不分 |
| 10 | **语义指向** | 标注箭头必须指向**已存在的元素**（框、循环、括号）；只是"说明位置"就用文字标签，不要拉箭头 | 箭头指向空白，读者不知道它在指什么 |

> 坐标建议用 0–100 的整数网格，1 个单位 = 0.1 英寸；方框、箭头、文字都落在整数或半数坐标上，改起来不出错。

## 三、四类典型反例（都实际发生过，画完先自查一遍）

**反例 1｜箭头穿框压字**：起点取在 `(cx+2, cy+10.4)`，正好落在"选实验"框内部，箭头从框里钻出来，
压住副标题"给定初始条件与参数"。
→ 改法：`c.arrow(b1, b2, "right", "left")`，端点由 `edge_point()` 算出并外移 `pad`。

**反例 2｜回路缺一段**：①②③④ 四个框，四条箭头里有两条的箭头尖停在框外空白处，
视觉上循环在 ③→④ 与 ④→① 两处断开。
→ 改法：每个箭头声明 `src/dst`；`check()` 会报"终点没有吸附在「④ 假设」的 top 边外侧（偏差 6.2）"。

**反例 3｜标签指向空白**："本文所在位置"配一条金色短箭头，箭头停在左右两块内容之间的空白，
既没指第三层框，也没指右侧循环。
→ 改法：把"本文所在位置"做成第三层框**下方的金色小字**（`c.note()`，居中于该框），**不留自由箭头**。

**反例 4｜留白失衡＋同组不齐**：手写 `figsize=(9.2, 4.4)` 与 `ylim=(4, 47)`，结果右边留白 13.9%、
上边只有 3.5%；四个循环框宽度 16.4 与 15.6 混用，环心文字偏右；层级箭头贴在方框最左边而不是居中。
→ 改法：`finalize()` 按内容包围盒反推画幅；`group()` 断言等大等距；层级箭头取 `"bottom"`/`"top"` 边中点。

## 四、骨架代码（照抄改内容即可）

```python
from draw_schematic import Canvas, GOLD

c = Canvas()                                  # 1 单位 = 0.1 英寸

# 左：三层问题（同组等大等距；第三层用金色边框）
c.title(0, 34.5, "领域的三层问题")
b1 = c.box(0, 23.75, 26, 7.5, "第一层：正问题", "模型已知，数值求解并观测")
b2 = c.box(0, 12.25, 26, 7.5, "第二层：反问题", "模型类已知，从数据定参数或定结构")
b3 = c.box(0,  0.75, 26, 7.5, "第三层：开放探索",
           "模型类未知，自主设计实验并发现支配方程",
           fc="#FBF2DE", ec=GOLD, lw=2.0)
c.group([b1, b2, b3], axis="v", name="三层问题")
c.arrow(b1, b2, "bottom", "top")              # 端点吸附到框边外，箭头居中
c.arrow(b2, b3, "bottom", "top")
c.note(13, -1.6, "第三层为本文所在位置", ha="center")   # 说明性文字，不用箭头

# 右：四步循环（矩形布局：四条水平/竖直箭头首尾相接，回路天然闭合）
c.title(32, 34.5, "本文自动化的循环（LLM 智能体 + 工具）")
s1 = c.box(32, 21.0, 20, 7.0, "① 选实验", "给定初始条件与参数")
s2 = c.box(64, 21.0, 20, 7.0, "② 观测", "数值实验返回时间序列")
s3 = c.box(64,  4.0, 20, 7.0, "③ 分析", "编码与可视化")
s4 = c.box(32,  4.0, 20, 7.0, "④ 假设", "提出或反驳候选模型")
# 分组按"行 / 列"分别断言：一行四个混在一个水平组里会误报间距不等
c.group([s1, s2], axis="h", name="循环上列")
c.group([s4, s3], axis="h", name="循环下列")
c.group([s1, s4], axis="v", name="循环左列")
c.group([s2, s3], axis="v", name="循环右列")
c.arrow(s1, s2, "right", "left")
c.arrow(s2, s3, "bottom", "top")
c.arrow(s3, s4, "left", "right")
c.arrow(s4, s1, "top", "bottom")
c.note(58, 16.0, "工具：代码执行\n绘图\n外部记忆", size=7.6, ha="center")

c.check()          # 几何断言：有问题直接报错并列出条数与位置
c.save("fig00-field-map.png")
```

示例的成品与可运行脚本见 `notes/figures/fig00-field-map.png` 与 `notes/figures/src-fig00-field-map.py`（按本规则画出的版本；修前版本的四类反例见第三节）。

## 五、自检与交付前清单

```text
python scripts/draw_schematic.py --check notes/figures/fig00-*.png
```

- [ ] `Canvas.check()` 无报错（端点吸附、无穿框、无悬空、无文字重叠、同组等大等距）
- [ ] `--check` 四边留白都 ≥ 2%，最大/最小 ≤ 2.5 倍
- [ ] 画幅与内容比例匹配（无大片空白）
- [ ] 每个箭头的语义读一遍：起点 → 终点是否就是正文那句话说的关系
- [ ] 标注类箭头都指向具体元素；只说明位置关系时用文字标签
- [ ] 图注标"自绘",并在正文写清"该图为流程示意图，无坐标轴"或各子图的横/纵轴含义
- [ ] 图内文字与正文术语一致（同一概念同一译名）

## 六、用其它工具画（PPT / draw.io / TikZ）时的等价要求

几何断言用不上，但规则 1–10 全部照样适用；导出 PNG 后仍要跑
`python scripts/draw_schematic.py --check <png>` 查留白与画幅，并人工放大核对箭头端点是否贴边、
回路是否闭合、标签是否压线。交付前把图按 300 dpi 导出，避免缩略图看不清。
